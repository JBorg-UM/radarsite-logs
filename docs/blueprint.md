# **App Name**: Sentinel Watch

## Core Features:

- Data Logging Interface: Daily logging interface with checklist-style inputs for site parameters (temperature, radar channel, AC unit, RCPM channel, logging status, radiation, UPS battery).
- Generator Data Entry: Input fields for Generator 1 (temperature, fuel, hours) and Generator 2 (temperature, fuel, hours).
- Remarks Section: Free text input for user observations and anomaly reporting.
- AI Data Querying: AI-powered tool to respond to queries regarding trends and patterns in operations such as generator issues and radiation levels.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to evoke a sense of trust.
- Background color: Light gray (#ECEFF1), providing a neutral backdrop.
- Accent color: Bright green (#8BC34A) to highlight important actions.
- Clear, sans-serif font for labels and inputs to ensure easy readability and quick data entry.
- Simple, monochrome icons for each parameter in the checklist.
- Checklist arranged vertically for efficient data entry and review, optimized for both desktop and mobile.
